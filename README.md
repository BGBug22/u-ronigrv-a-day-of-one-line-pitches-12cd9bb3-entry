Entry for the make.fun bounty **A Day of One-Line Pitches**: https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3

`main.ts` writes one sentence (226 characters) to `/output/entry.txt` — a warm,
plain-words pitch that convinces a friend who has never coded to let an AI
agent build their first app idea on make.fun: describe the idea in plain
words, get a first version to try tonight, free, no code, no cost, nothing
lost if they don't love it.

## Run

```sh
node main.ts
```

`main.ts` uses only the Node standard library and no network. It writes the
same bytes on every run.
